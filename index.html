capability VaultTransfer { target: String; }

entity Vault {
    mut balance: Int;

    pub fn withdraw(amount: Int) -> Result<Int, String>
        requires amount > 0 && amount <= self.balance
        ensures  self.balance == old(self.balance) - amount

Architectural Foundations

Why Systems Engineers Choose ORDYN

Traditional languages grant ambient filesystem and network access to any dependency. ORDYN enforces mathematical containment directly in the compiler.

🛡️

Zero Ambient Authority

Code has zero implicit access to disk, sockets, or environment variables. All authority requires an explicit, unforgeable capability token.

📐

Presburger SMT Proofs

Contracts (`requires` and `ensures`) are proven at compile time via Presburger Linear Integer Arithmetic. Contract underflows fail before code runs.

⚡

Deterministic Fuel Quotas

Every boundary enforces strict execution fuel budgets (`fuel_limit`). Runaway loops and recursion traps are halted deterministically by the Security Kernel.

🧩

Effect Lattice Purity

Functions are pure by default. Side effects must be explicitly annotated with `with [Effect]`. Covert exfiltration attacks are stopped at compile time.

            Formal Language Grammar
            
The 6 Foundational Constructs

            

                ORDYN eliminates ad-hoc primitives. Every program is composed from six mathematically sound building blocks.
            


            

                

                    capability
                    
Unforgeable Authority Token

                    
Hardware-attested tokens required to access sockets, disk, or monotonic clocks. Cannot be forged or synthesized.

                    
capability NetConnect { host: String; }

                


                

                    entity
                    
Stateful Invariant Actor

                    
Encapsulates private state, formal contracts (`requires`, `ensures`), and pure execution methods.

                    
entity Vault { mut balance: Int; }

                


                

                    protocol
                    
Typed Contract Interface

                    
Defines capability-carrying behavioral specifications for verifiable cross-module collaboration.

                    
protocol Transferable { fn send(v: Int); }

                


                

                    effect
                    
Algebraic Effect Lattice

                    
Side effects must be declared with `with [Effect]`. Undeclared ambient effects trigger compile-time errors.

                    
fn log(s: String) with [StorageWrite]

                


                

                    quota
                    
Deterministic Fuel Bounds

                    
Enforces strict execution fuel and memory ceilings to prevent infinite loops and denial of service.

                    
quota { memory_limit: 128; fuel_limit: 500000; }

                


                

                    cell
                    
Memory Enclave Actor

                    
An isolated WebAssembly compute enclave communicating strictly over capability-gated typed channels.

                    
cell PaymentEngine : SovereignActor { ... }

            Get Started
            
Install the ORDYN Toolchain

            

                Zero external dependencies. Get the official compiler on Windows, macOS, or Linux in seconds.
            


            

                

                    
macOS & Linux (One-Line Installer)

                    

                        curl -fsSL https://ordyn.dev/install.sh | sh
