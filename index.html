Why ORDYN?

Performance

ORDYN is blazingly fast and deterministic: with zero ambient runtime overhead and single-pass Pratt parsing, it compiles directly to native WebAssembly and SSA machine representations. Run high-throughput services with compiler-enforced fuel budgeting.

Reliability

ORDYN eliminates entire classes of logic bugs and runtime underflows at compile-time. Formal pre/post-conditions (`requires` and `ensures`) are mathematically verified by Presburger SMT arithmetic, guaranteeing self-balancing ledgers and memory bounds.

Productivity & AI Safety

ORDYN has zero ambient authority: functions are pure by default, and capabilities to touch disk, network, or env must be explicitly granted. AI coding agents (Claude Code, Cursor) and vibe-coders cannot hallucinate unauthorized side effects or runaway loops.

AI-Native Computing

Built for the AI Era: Why Vibe Coders Need ORDYN

When you vibe code with Claude Code, Cursor, or Copilot, the AI frequently leaks authority, writes silent contract underflows, or generates infinite loops. ORDYN replaces guesswork with compiler-level mathematical certainty.

🛡️

Zero Ambient Authority

No hidden API key leakage or unauthorized network requests. Even if an AI writes malicious or compromised code, it cannot touch disk, env, or sockets without an explicit capability token.

📐

Hallucination Immunity

Preconditions (`requires`) and postconditions (`ensures`) are mathematically proven before runtime by Presburger SMT logic. Business rule violations fail at compile time.

⚡

Runaway Loop Protection

AI-generated `while` loops cannot burn CPU indefinitely. The Fuel Governor automatically budgets execution ticks (`fuel_limit`), trapping infinite loops safely.

                Formal Language Grammar
                
The 6 Foundational Constructs

                

                    ORDYN avoids ad-hoc primitives. Every program is built from six composable, sound architectural building blocks.
                

            


            

                

                    capability
                    
Unforgeable Authority

                    

                        Hardware-attested tokens required to touch sockets, disk, or monotonic clocks. Cannot be forged or synthesized.
                    

                    
capability NetConnect { host: String; }

                


                

                    entity
                    
Sovereign State & Invariants

                    

                        Stateful actors encapsulating private fields, verified contracts (`requires`, `ensures`), and pure methods.
                    

                    
entity Vault { mut balance: Int; }

                


                

                    protocol
                    
Typed Behavioral Interface

                    

                        Defines capability-carrying contract methods for secure cross-module collaboration.
                    

                    
protocol Transferable { fn send(v: Int); }

                


                

                    effect
                    
Side-Effect Lattice

                    

                        Algebraic side-effects declared with `with [Effect]`. Ambient unhandled effects cause compile-time errors.
                    

                    
fn log(s: String) with [StorageWrite]

                


                

                    quota
                    
Deterministic Resource Limits

                    

                        Hardware bounds defining maximum memory MB and execution fuel limits to neutralize infinite loops.
                    

                    
quota { memory_limit: 128; fuel_limit: 500000; }

                


                

                    cell
                    
Sandboxed Runtime Actor

                    

                        A memory-isolated compute enclave communicating strictly through typed capability channels.
                    

                    
cell PaymentEngine : SovereignActor { ... }

            Installation
            
Quickstart in 60 Seconds

            

                Get up and running with the official ORDYN compiler toolchain on Windows, macOS, or Linux.
            

        


        

            

                
Step 1: Install the ORDYN Toolchain

                

                    # macOS & Linux:
curl -fsSL https://ordyn.dev/install.sh | sh
                    
                

                

                    # Windows (PowerShell):
irm https://ordyn.dev/install.ps1 | iex
                    
                

            


            

                
Step 2: Initialize & Verify a Sovereign App

                

                    ordyn init sovereign-app && cd sovereign-app
ordyn verify main.ordyn
