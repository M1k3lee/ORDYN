THE AI CODING DILEMMA

In Python or Node, AI-generated code has total ambient authority.

If an AI agent accidentally writes a rogue outbound network call, leaks your environment keys, or installs a compromised dependency, the runtime executes it without hesitation. In ORDYN, ambient authority is physically impossible. Code cannot touch a file, socket, or environment variable unless you granted that explicit capability in a boundary.

                Foundational Architecture
                
The Six Foundational Constructs

                

                    ORDYN does not assemble disjoint security libraries. Security is unified into 6 first-class grammatical elements.
                

            


            

                

                    

                        01
                        
Entity

                    

                    
Stateful domain objects with strictly encapsulated state, controlled mutability, and invariant-bound methods.

                    
entity Wallet {
    let id: String;
    mut balance: Int;
}

                


                

                    

                        02
                        
Capability

                    

                    
Unforgeable authority tokens required to invoke privileged operations. Ambient authority is banned.

                    
capability HttpConnect {
    host: String;
    port: Int;
}

                


                

                    

                        03
                        
Contract

                    

                    
First-class preconditions, postconditions, and invariants statically proved by SMT solvers.

                    
contract Solvency {
    invariant balance >= 0;
    requires amount > 0;
}

                


                

                    

                        04
                        
Flow

                    

                    
Explicit, deterministic state transitions governed by declared algebraic effect lattices.

                    
flow Transfer(amt: Int)
    with [StorageWrite, Audit] {
    Debit -> Credit -> Settle;
}

                


                

                    

                        05
                        
Boundary

                    

                    
Isolated sovereign execution sandboxes with explicit capability grants and deterministic fuel quotas.

                    
boundary SettlementCore {
    grant StorageWrite { path: "tx/" };
    quota { fuel_limit: 1000000; }
}

                


                

                    

                        06
                        
Interface

                    

                    
Behavioral contracts defining capability-gated interactions across sovereign component boundaries.

                    
interface KeyStore {
    fn get(k: String) -> String
        with [StorageRead];
}
